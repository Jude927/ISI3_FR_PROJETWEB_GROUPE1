🔄 Migration Firestore

Mise à jour de la structure de la base de données pour le système de tutorat P2P

⚠️ Attention

  • Ce script va modifier ta base de données Firestore
  • Il ajoute des champs aux collections existantes
  • Il ne supprime AUCUNE donnée existante
  • À exécuter UNE SEULE FOIS
  • Assure-toi d'avoir une sauvegarde (optionnel mais recommandé)

📋 Ce que fait ce script

Étape 1 : Ajoute peerId, isOnline, lastSeen à la collection "users"

Étape 2 : Ajoute peerId, isOnline, isAvailable, rating, totalSessions à "teachers"

Étape 3 : Crée la collection "students" pour tous les utilisateurs avec role="student"

Étape 4 : (Optionnel) Ajoute des matières de test aux tuteurs

Étape 5 : Affiche un résumé de la base de données
